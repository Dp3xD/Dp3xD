## 🔬 Featured Projects

### [Does Visual Grounding Help a Small Language Model Learn More Efficiently?](https://github.com/Dp3xD/BabyLM)
Controlled pretraining study under BabyLM Challenge 2026 constraints — GPT-2 trained from scratch, text-only vs. visually grounded, on a matched word budget.
**Finding:** grounding cut perplexity by 39% (36.27 → 22.29) but slightly hurt grammatical accuracy (BLiMP 60.43% → 58.46%, p = 0.001).

### [Before the Fact-Check: Detecting Misinformation Through Linguistic Style](https://github.com/Dp3xD/misinformation-detection-linguistic-style)
DistilBERT + XGBoost on interpretable linguistic features, stress-tested cross-domain (trained on LIAR, tested on FakeNewsNet PolitiFact).
**Finding:** the best in-domain model (F1 0.673) collapsed to F1 = 0.000 cross-domain once its speaker metadata disappeared — strong benchmarks can be undeployable.

### [Oriented Object Detection for Aerial Imagery](https://github.com/Dp3xD/oriented-object-detection-aerial-images)
Anchor-free oriented object detector (BBAVectors, ResNet101) adapted from the DOTA architecture to a custom drone dataset. **84.71% mAP** after class rebalancing.

### [GSD Estimation for UAV Imagery](https://github.com/Dp3xD/gsd-estimation-uav-imagery)
Ground Sample Distance estimation for drone imagery via PCA + linear regression on annotated aerial frames. **Test RMSE 0.0242, ~89% accuracy.**
